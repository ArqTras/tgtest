# How to feed Kontekst with sources

Kontekst answers from three places: the current chat, facts learned from earlier messages, and texts you mark as project sources.

Add a source in three ways. In Telegram send `/source` with a full page URL. On the status page paste a URL or a text snippet with the admin password. You can also drop a `.md` or `.txt` file into the container sources folder; the bot picks it up within a minute.

Delete this file once you add your own project materials. While it remains, the bot may quote this guide.
